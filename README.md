# FundFlow – Crowdfunding Platform

## About the Project
FundFlow is a web-based crowdfunding platform that helps users create campaigns, support causes through donations, and track fundraising progress.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite

## Main Features
- User Registration and Login
- Campaign Creation
- Campaign Cards
- Donation Flow
- Funding Progress Bar
- Donor List
- Demo Payment Simulation

## Team Project
Developed as part of the CODESTACK CARNIVAL coding challenge.

## How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

**Note:** The payment feature is simulated for demonstration only. No real money is transferred.
